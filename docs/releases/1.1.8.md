Pi-Bolt 1.1.8 is [1.1.7](1.1.7.md) with one change: it ships no bundled skills.

### Removed

- **The bundled `pibolt-mobile-ui` skill**: Pi-Bolt no longer registers a skill of its own into every session. A session starts with only the skills the user and their projects
  provide; builds no longer package a `skills/` directory. The mobile UI kit itself is unchanged — extensions still
  describe views with `ctx.ui.setView()`, and `pi-bolt mobile-ui check` and `pi-bolt mobile-ui preview` still work;
  the kit's documentation ([mobile-ui.md](../../packages/coding-agent/docs/mobile-ui.md)) is the reference for writing
  views.

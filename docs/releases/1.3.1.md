Pi-Bolt 1.3.1 is upstream Pi-Bolt [1.3.0](1.3.0.md) (Pi 1.6.0, new engine) with this fork's Linux x86-64 releases, signed updates, Herdr identity and offline launcher repair. It builds on the signed `bolt-v1.3.0` runtime. Version 1.3.0 was not published from this fork: its macOS release checks failed on the doctor fix below.

### Fixed

- **`pi-bolt doctor`** no longer reports an installer launcher as "not this Pi-Bolt" when the installation path contains a symlink, such as macOS's `/var` -> `/private/var`. It now resolves the launcher's runtime path the same way it resolves its own executable.
